# Third-party license materials — preview

The subdirectories contain notices and package metadata collected from the
Windows build environment, plus the FFmpeg build information and GNU license
texts. Package metadata may include notices for optional or bundled code.
The project license and overview are in the adjacent LICENSE and NOTICE.md.

This is an incomplete preliminary collection, not a statement of compliance.
In particular, it does not establish that all notices for Qt's and Pillow's
embedded third-party libraries, FFmpeg's codec dependencies, or Windows
runtime components are present. Corresponding source code and build details
for the exact Qt, FFmpeg and HEIF binaries have not been verified or supplied.
