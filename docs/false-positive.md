# Ложное срабатывание антивируса на PROMETHEA Drop

Документ для обращения в антивирусные лаборатории (Kaspersky, Microsoft, Dr.Web)
и для внутренней проверки: почему эвристика видит троян и что приложить к заявке.

## Что сообщает антивирус

```
PDM:Trojan.Win32.Generic
Объект: D:\WORK\promethea-drop\dist\PrometheaDrop.exe
```

`PDM` — это Proactive Defense Module у Kaspersky, то есть **поведенческая**
эвристика, а не совпадение с базой сигнатур. Вердикт выносится по действиям
процесса, а не по коду.

## Почему эвристика срабатывает

1. **PyInstaller onefile.** Один exe распаковывает себя в `%TEMP%\_MEIxxxx`,
   запускает дочерний процесс и загружает `python3xx.dll`. Для эвристики это
   классический паттерн упаковщика/дроппера.
2. **Опрос клавиатуры.** `trigger.py` в цикле вызывает `GetAsyncKeyState(VK_SHIFT)`,
   чтобы поймать Shift во время перетаскивания в Проводнике. Это тот же вызов,
   которым пользуются кейлоггеры, поэтому поведенческий детектор реагирует
   на саму последовательность вызовов.
3. **Нет цифровой подписи и репутации.** Файл собран локально час назад,
   в базе репутации его нет — для PDM это «неизвестный бинарник, который
   распаковывается, опрашивает клавиатуру и трогает файлы».
4. **Работа с Проводником и файлами.** Приложение перечисляет окна, перехватывает
   перетаскивание, перемещает результаты и отправляет их в корзину.

Ничего из этого не является вредоносным, но набор совпадает с шаблоном.

## Что делать

| Шаг | Эффект |
|---|---|
| Собирать **onedir** вместо onefile (`scripts/build.ps1`) | убирает самораспаковку в `%TEMP%` — самый частый триггер PDM |
| Подписать exe (OV/EV сертификат, `signtool`) | снимает «неизвестный издатель», даёт репутацию |
| Отправить файл в лабораторию как ложное срабатывание | вердикт снимают точечно для хеша |
| На машине разработчика: исключение на папку проекта | чтобы сборка не удалялась во время работы |

## Текст заявки (RU)

```
Здравствуйте. Прошу проверить на ложное срабатывание.

Файл: PrometheaDrop.exe
Версия: 0.1.0
SHA-256: <подставить>
Размер: <подставить> МБ
Вердикт: PDM:Trojan.Win32.Generic

Приложение — локальный конвертер файлов с открытым исходным кодом.
Работает без сети, не ставит служб,
не создаёт автозапуск без явного согласия пользователя.
Собрано PyInstaller (onedir/onefile), интерфейс PySide6.

Поведение, которое могло вызвать детект:
- приложение ждёт Shift во время перетаскивания файла в Проводнике
  (GetAsyncKeyState), чтобы показать радиальное меню;
- PyInstaller распаковывает компоненты во временную папку при запуске;
- после конвертации файл-результат сохраняется рядом с исходником,
  по кнопке «Undo» перемещается в корзину.

Ссылка на исходники: <репозиторий>
Прошу добавить файл/хеш в исключения либо уточнить, какое поведение
считать нежелательным, чтобы его изменить.
```

## Текст заявки (EN)

```
This file is reported as PDM:Trojan.Win32.Generic (behavioural detection).

PrometheaDrop.exe, version 0.1.0, SHA-256 <hash>, built with PyInstaller
and PySide6. It is an open-source local file converter: no network access,
no services, no hidden persistence.

Likely triggers: PyInstaller self-extraction to %TEMP% and polling
GetAsyncKeyState to detect Shift while a file is dragged in Explorer.

Please re-check and whitelist the hash, or tell us which behaviour to change.
Source: <repository>
```

## Куда отправлять

- Kaspersky OpenTIP: `https://opentip.kaspersky.com/` → загрузить файл → «Ложное срабатывание».
- Kaspersky false positive form: `https://support.kaspersky.com/ru/false-positives`.
- Microsoft: `https://www.microsoft.com/en-us/wdsi/filesubmission`.
- Dr.Web: `https://vms.drweb.com/sendvirus/`.

Заявку стоит отправлять на **подписанный onedir-билд**, а не на onefile:
меньше поводов для повторного срабатывания.
