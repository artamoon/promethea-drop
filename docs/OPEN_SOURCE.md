# Исходный код PROMETHEA Drop

Код проекта и изменения доступны по MIT License, указанной в `LICENSE`.
Уведомление об авторских правах исходного проекта сохранено в этом файле.
MIT остаётся лицензией этого кода; это не меняет лицензии зависимостей и не
означает, что собранное приложение целиком можно распространять только по MIT.

Локальный архив проекта создаётся командой:

```powershell
.\.venv\Scripts\python.exe scripts\package-source.py
```

В архив входят исходники приложения, тесты, скрипты, конфигурация сборки,
документация по запуску и собранные тексты сторонних лицензий. Он исключает
виртуальное окружение, сборки, личные файлы и бинарные файлы FFmpeg. Для
сборки Windows с аудио и видео нужен совместимый FFmpeg в `vendor/ffmpeg/bin`;
описание прежней сборки — в `vendor/ffmpeg/BUILD.txt`.

**Архив — снимок исходников проекта, не полный подтверждённый комплект
Corresponding Source для текущего exe.** Зависимости в `requirements.txt` не
зафиксированы полностью. Исходники и патчи конкретных бинарных сборок FFmpeg,
Qt и HEIF не подтверждены; уведомления для их зависимостей тоже неполны.
Сведения о текущей среде — `docs/build-environment.txt`, но это не гарантия
воспроизводимости. PyMuPDF и pillow-heif/x265 требуют отдельного решения по
условиям распространения и совместимости. Подробности — в `LICENSE_AUDIT.md` и
`INSTALLER_LICENSE_CHECK.md`. До разрешения этих вопросов не считать текущий
установщик готовым к публичной раздаче.

Чтобы делиться исходниками вместе с будущим выпуском, нужно опубликовать код,
соответствующий конкретному бинарнику, обеспечить доступ к необходимым исходным
материалам зависимостей и инструкциям сборки, и выполнить применимые лицензии.
Исходный код проекта опубликован: https://github.com/artamoon/promethea-drop.
